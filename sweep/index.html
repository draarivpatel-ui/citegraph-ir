Threshold Coverage False answers Accuracy ECE AUROC

ECE is the expected calibration error of the score against the labels. It barely moves across the sweep because it measures how well the score magnitude matches the label frequency, and a heuristic score is not trained to be calibrated in absolute terms. AUROC, which only needs the order of the scores to be right, is the more honest readout of this score.
